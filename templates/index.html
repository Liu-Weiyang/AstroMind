欢迎使用 AstroMind

几分钟带你快速上手

1设置 API 密钥
  • 点击「API 设置」展开面板
  • 粘贴你的 ADS Token 和 DeepSeek API Key
  • 点击「保存设置」
2搜索关键词
  • 在搜索框输入你感兴趣的天文学话题
  • 或点击「常用搜索」快捷标签
  • 等待 AI 生成研究介绍与论文分类
3深入阅读
  • 点击「查看详情」查看每篇论文的总结、扩展分析与综合比较
  • 点击「跨领域连接」获取跨学科方法迁移建议
  • 点击「更新」可重新生成介绍
