👋 欢迎使用「今日天文学」

几分钟带你快速上手

1 设置 API 密钥
  • 点击「⚙️ API 设置」展开面板
  • 粘贴你的 ADS Token 和 DeepSeek API Key
  • 点击「保存设置」
2 搜索关键词
  • 在搜索框输入你感兴趣的天文学话题
  • 或点击「常用搜索」快捷标签
  • 等待 AI 生成综述
3 深入阅读
  • 引用论文的段落会有「📖 查看详情」按钮
  • 点击后右侧会展开详细分析
  • 支持数学公式渲染，可点击论文链接跳转
